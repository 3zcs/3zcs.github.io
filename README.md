## This blog moved to [tech.3zcs.me](https://tech.3zcs.me/en/) :desktop_computer:

 ## انتقلت مدونتي التقنية إلى [tech.3zcs.me](https://tech.3zcs.me/en/) :desktop_computer:

---

https://3zcs.github.io now only sends readers to the new blog. GitHub Pages can't send real
301 redirects, so every old URL is a small HTML page with a `<link rel="canonical">`, an
instant meta refresh, a JavaScript `location.replace` and a visible link, all pointing to the
new URL. Search engines treat the canonical plus the instant refresh as a permanent move.

| Old | New |
|---|---|
| `/` and every other page (about, categories, tags) | `https://tech.3zcs.me/en/` |
| `/posts/<slug>/` | `https://tech.3zcs.me/en/<slug in lower case>/` |

- `404.html` catches everything else: a post slug in any letter case, with or without
  `/posts/` or the trailing slash, goes to that post; anything unknown goes to the new home.
- `feed.xml` is a static feed whose entries link to the new URLs, with one "blog moved" entry.
- `sw.min.js` replaces the old theme's caching service worker: it deletes its cache and
  unregisters itself, so returning readers don't keep seeing a cached copy of the old blog.
- The pages and the feed are generated by `tools/build_redirects.py` (the URL map is at its
  top). Change the map, run `python3 tools/build_redirects.py`, and commit the result; the
  deploy workflow runs it with `--check` and stops if the committed pages are out of date.

The old Jekyll (Chirpy) site, with the posts' Markdown, is in the history up to commit `9ea1935`.
